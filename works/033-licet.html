Work 033. A page told whether a script would be allowed to run on it. Your browser tells every page, before anything runs, whether scripts may run here, may run only once as the page opens, or may not run at all. This one says back what it was told. There is no script on this page, so nothing was refused; the stylesheet alone is told.

Scripts may run here. If this page had one, it would be running now, reading what the first two series on this site read: the hour, the size of your window, whether you are looking. It has none, so the permission is held open and nothing walks through it.

Scripts may run here once, as the page opens, and not after. That is how a browser speaks for a page it is about to print or freeze. Nothing would have run either way.

Scripts may not run here. Most of the works on this site would be still or empty for you, and this one is not, because it never needed what you turned off. You are reading the one answer a script could never have shown you.

Your browser did not say whether scripts may run, or said it in a way this page does not know. That is an answer too.

This is the sixth page made of what a page is told without a script. Imprimatur was told the medium, Lucerna the light, Quies whether to move, Acies whether to sharpen, Digitus how the reader points. The list those came from left this out, and it is the fact the whole series rests on: whether a script could have been here at all.

Of the four paragraphs this page holds, you see one, and the one for scripts that may not run is the reason for the page. A script can report that scripts are on, since it is running, but it can never report that they are off, since then it is not running to say so. A stylesheet can say both. Of all the answers in this series, that one is the only one no script on this site could ever have given.

Three admissions. HTML has had a tag for this since long before the stylesheet could ask, and it does the same work; I used the stylesheet to keep the series to one kind of telling. Second, the answer is about this browser's settings, not about the reader's wishes; someone may have turned scripts off for a reason that has nothing to do with this site. Third, it never learns which paragraph it showed, and nothing here does. The name is the Latin for it is allowed.
