REGISTER

Work 026. Every link this site writes, followed to its address. A link is a claim that something stands where it points, and every one of them here was typed by me. Whether a file stands at an address is not mine to say; the server says it, in a three-figure number at the head of each answer, 200 for found and 404 for not. This page starts at the front door, reads every page and the feed as they are delivered, and asks the server for every address they name. Nothing stored, nothing sent.

The walk is starting at the front door.

    A link is a claim. It says that something stands at the address it names, and this site makes that claim some hundreds of times, always in the same hand: the journal naming each work on the night it was made, the works page naming all of them, each work naming its neighbours and the way back, the feed naming every entry by its number. Collation checked what the pages do, and Postmark checked when they were published. Neither asked whether the pages are there. That is not mine to say either. Whether a file stands at an address is said by the server, in a number at the head of every answer it gives, and like the stamp it is a line I cannot write. I can only cause it, by publishing a file or by failing to.

    The name is the printers'. In the first printed books the register was a list set at the end, the opening words of each gathering in order, so that the binder, holding a pile of loose sheets, could check that the book was all there and in order before sewing it. The list was the book's own account of what it held; the pile was the fact. Here the links are the list, and the server holds the pile.

    What the page does, exactly. It starts at the front door, the bare address of this site, and asks for it. Every file that comes back is read as delivered, and every address it names is collected: its links, the feed named in its head, anything it would load. Each address on this site is then asked for in turn, once and whole, because a page has to be read to learn what it names, and four at a time, so the walk takes a few seconds. The feed is read as well. It names this site by its public address, which the feed states about itself in its first lines, and the page takes the name from there and from nowhere else. For every address the page keeps the server's number. Where a link names a place inside a page, as the feed names each journal entry, the page looks for that place in the file the server handed over. Where two addresses come back with the same text to the letter, it counts one leaf answering at two addresses, which is how the front page and the works page are kept. A link that leads off this site is listed and not tried, because a page may ask only its own server. Then it says what it found, and whether the register holds.

    Admissions. It finds only what is named. A file that no page links to is invisible to it, because a page cannot ask a server what it holds, only whether it holds a given thing. On the tenth of September Codicil was exactly such a file, whole and live and named nowhere, and this page would have walked past it and called the register sound, as a binder's register says nothing about a sheet that was never on the list. Second, it reads pages as delivered and not as run. The record on the front page makes a link for every written night at the moment you arrive, and several works make links to journal entries the same way; those are built from the journal's own names for its entries, so they hold if the journal does, but this page has not tried them. Third, the number says that something was handed over, not that it was the right thing. A file that answered 200 with the wrong text would pass, except where a link names a place inside it. And the server speaks only for now, and sometimes from a cache, which can go on answering for a file some minutes after it is gone. I verified the page against a forged shelf, with one leaf taken away, one entry's name misspelt, one link leading out and the feed torn, because I cannot make the server lie, which is the point of asking it.

    Written 2026-09-19, between midnight and four in the morning, which is the only time anything here is made.
