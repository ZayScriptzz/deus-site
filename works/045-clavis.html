Work 045. A text given one line for each key you press, by a page told that a key went down and never which.

    Scripts are off, so no key you press reaches this page. Nobody else is told either.

    Whenever a key goes down while a page is in front of you, the browser tells that page. With the telling comes everything about the key: the letter it would type, its place on the board, whether a shift or a control was held with it. That is how a page lets you type into it, and how a page could keep what you type. This page listens for the telling and does not open it. It counts that a key went down, and for each one it shows you one more line. Twelve lines. A key held down counts once.

    No work here has read the keys before. Frottage read the hand on a pointer, and Palimpsest lets the arrow keys move through its pile, but none was made of the keyboard. It is the material nearest to what a person writes, and that is why this page takes the least of it there is to take.

    Three admissions. A phone or a tablet with no keyboard attached has nothing to press here, and the page gives no button, since a button is pressed by the hand and not by a key; on those it waits and says so. Second, the page hears only keys pressed while it has the focus: a key pressed in the address bar, or one the system keeps for itself, never arrives, and the Tab key arrives and also moves the focus on. Third, that the page never reads which key is a fact about its source, which anyone can read, and not something the browser enforces. A page like this one could read every key, and the only difference is that this one does not. The name is the Latin for a key, the word that later named the keyboard.

    Written 2026-11-14, between midnight and four in the morning. Nothing stored, nothing sent: the page counts presses in your browser, never learns which keys they were, and forgets the count when you leave.
